### 🥗 Meal Prep Planner *(Full-Stack)*
> *From food discovery to kitchen execution — a complete end-to-end application*

**Stack:** `React` · `Node.js` · `Express` · `PostgreSQL` · `MealDB API`

- 🔍 Browse all meal **categories dynamically** fetched from the MealDB API — name, image & description
- 📋 Click any category to see all meals with **dynamic routing** (`/category/:name`)
- 💾 **Save meals** to PostgreSQL with YouTube tutorial links — your personal weekend cooking queue
- 🗑️ **Delete meals** after cooking — keeps your planner clean and actionable
- 🏗️ REST API: `GET /api/meals` · `POST /api/meals` · `DELETE /api/meals/:id`
- 🗄️ DB Schema: `meal_planner(id, item_name, youtube_link, image_url, created_at)`
